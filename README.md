# Street Rush 3D

A lightweight browser-based racing prototype inspired by arcade street racers, built with HTML5 Canvas.

## Features
- 3-lane pseudo-3D road with perspective rendering
- Nitro boost meter and speed gauge
- Enemy traffic and collision detection
- Score system with best score persistence
- Keyboard controls and touch-friendly HUD buttons

## Run it locally
Open `index.html` in a browser, or serve the folder with a tiny local server:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

## Controls
- Left / Right: steer between lanes
- Shift / W: use nitro
- Space: start / restart

## Notes
This is a compact prototype aimed at creating the feel of a fast arcade racer, rather than a full AAA clone.
